# Материалы для Mortal Sales

Сюда кладутся исходники новой игры. Из этих папок ничего не публикуется напрямую.

```
new-game/
├── backgrounds/    фон арены (сейчас arena.jpg — копия лежит в public/assets/sprites/bg_arena.jpg)
├── animations/     дополнительные позы героев — сюда кладёте вы, подключаю я
└── audio/          музыка и голос (в git не попадает)
```

## animations/

Позы статичные (не покадровая анимация) — по одному прозрачному PNG на позу. Конвейера сборки нет: положите файлы и скажите мне,
я приведу их к масштабу героя и подключу. Чем больше поз одного хода, тем разнообразнее бой — они выбираются случайно.

Имена файлов: `<ход>_<номер>.png` в папке героя (`СР1 - Лев`, `СР2 - Скрудж`, `СР3 - Гринч`, `СР 5 - йода`, `СР6 - Незнайка`, `СР9 - миньон`).

| Ход | Что это | Где используется |
|---|---|---|
| `attack_1`… | удар рукой/оружием | серия ударов |
| `kick_1`… | удар ногой | серия ударов |
| `heavy_1`… | сильный/финальный удар | последний удар серии, «добивание» |
| `hurt_1`… | получил удар | реакция на удар |
| `stun` | оглушён | ярус «перевес» |
| `knockdown` | лежит на земле | ярус «доминирование» |
| `fly` | в полёте | ярус «разгром» (отлёт) |
| `ko` | побеждённый | финал дня, конец недели |
| `win` | победная поза | финал дня |

Что нужно знать:

- Прозрачный фон, персонаж смотрит **вправо** (в сторону соперника). Правая команда зеркалится сама; если на одежде надпись (худи Льва «Актион»),
  приложите левостороннюю версию `<ход>_<номер>_L.png` — она будет использоваться вместо зеркала.
- Рисуйте в том же масштабе, что `Персонаж.png`. Если поза крупнее/мельче — напишите, подгоню.
- Чего нет, того игра не покажет позой, а изобразит движением (отшаг, вспышка, вращение): всё работает и без этих файлов.

*(Для тех, кому интересно, как это подключается: текстуры лежат в `game/public/assets/sprites/hero_<имя>_<ход><n>.png`, список ключей — в
`game/src/game/config/heroMoves.json`, читает его `RosterConfig`. `tools/build-sprites.py` собирает только стоячие позы и три исходных удара.)*

## backgrounds/

`arena.jpg` — текущий фон (храм со знаком инь-ян, 1920×1080). Пол занимает нижние ~20 % кадра: бойцы стоят на трёх узких линиях
(`ARENA.LANES` в `Constants.ts`). Новый фон: положите сюда, скопируйте как `game/public/assets/sprites/bg_arena.jpg` и скажите мне — подберу линии под него.

## audio/

Файлы, которые кладёте вы (я их не скачиваю и не публикую):

- `theme.mp3` — музыка боя;
- `fight.mp3` — голос «Fight!»;
- по желанию: `finish.mp3` (Finish him), `ko.mp3`, `hit1.mp3`…

Папка `audio/` и `game/public/assets/audio/` исключены из git: репозиторий и GitHub Pages публичные, а музыка чужая.
Для офисного экрана файлы копируются на компьютер вручную.
