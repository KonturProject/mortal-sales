## Задача

На основе готовой игры «Отделы против дракона» сделать **Mortal Sales**: шесть героев-руководителей групп дерутся на экране тремя парами, три слева и три справа, при удалённой перспективе; поводом для боёв служат загрузки счетов от 20 минут; день завершает кнопка в админке; руководители копят звёзды за выигранные дни (до 5 за неделю), матч недели выигрывает тот, у кого их больше; рейтинг менеджеров в абсолютных числах. Дракон не нужен. Музыка и голос «Fight!» — позже, дополнительные позы героев — позже.

## Хронология

### 1. Изоляция (`36d53a8`, 29.09)

Копия смотрела на боевые ресурсы: `git remote` на репозиторий игры, `npm run deploy` в её `gh-pages`, боевой Web App в `config.json`, боевая таблица в `Code.gs`. Сделано: remote удалён; `deploy-guard.mjs` не даст опубликовать без `origin` или в репозиторий боевой игры; `config.json` без адреса (`useMock: true`); `SPREADSHEET_ID` — заглушка; переименованы пакет, ключ звука в `localStorage`, заголовки страниц; созданы папки `new-game/{backgrounds,animations,audio}`; музыка не попадает в git; сохранён утверждённый план как спецификация.

### 2. Арена и бой (`be61d1b`, 29–30.09)

- **Планировщик ударов** `FightPlanner`: чистая функция, ярусы боя (равный / перевес-оглушение / доминирование-нокдаун / разгром-отлёт), отстающий всегда бьёт.
- **Боец** `Fighter`: ход к центру, выпад по ширине позы, реакции (отшаг, оглушение со звёздочками, падение, эпичный отлёт со спином и тряской), подъём, победа, поклон; работает без дополнительных поз.
- **Режиссёры и сцены**: `FightDirector` (раунд и финал «FINISH HIM!»), `ArenaScene` (три линии, очередь раундов и финалов, табло недели), `HUDScene` (лайфбары, звёзды, рейтинг, баннеры, статус).
- **Элементы HUD**: `PairLifebar`, `StarRow` (загорающаяся звезда), `ManagerBoard` (рейтинг постранично).
- Удалены дракон, гора золота, Круэлла, «настроение простоя»; обновлены события, состояние, ростер.
- Фон храма; пол занимает ~20 % кадра → три узкие линии бойцов, рейтинг менеджеров вынесен в две боковые панели.

### 3. Бэкенд и админка (`4ce593d`, 01.10)

- **`Code.gs` переписан** вокруг читаемых вкладок таблицы: справочник сотрудников, подразделения, пары, история загрузок, завершённые дни, настройки. Загрузка «всё или ничего» со сверкой накопительных значений; завершение дня / новая неделя / ручная правка звёзд; ключ экрана для публичного GET; кэш; защита от формул, дублей и повторной отправки.
- **Админка с нуля**, семь вкладок: День и неделя, Загрузка данных (xlsx/csv/вставка + предпросмотр с проверками), Сотрудники (перевод, активность, переименование, удаление, импорт справочника), Пары и отделы, История, Анимации, Доступ.
- **Бой по среднему на сотрудника** во всей цепочке: планировщик, финал, лайфбары («среднее» и «сумма сч. · чел.»), админка.
- Тестовый стенд Google-сервисов в памяти (`gas-harness.mjs`), мок-бэкенд с выдуманными сотрудниками, парсеры файлов с тестами на настоящих xlsx.
- Персонажи крупнее (~14 %); `CLAUDE.md` и документация переписаны; старые документы помечены историческими.

### 4. Полная проверка (`d2f8226`, 01.10)

Подробности и список найденных ошибок — в [06-proverka.md](./06-proverka.md). Главное:

- **Цель 1,20 на сотрудника** стала настройкой бэкенда и админки; разрыв средних измеряется в долях цели (прежняя мера «доля от суммы пары» считала 1,92 : 2,42 равным боем).
- Исправлены гонки и залипания: прерванное движение бойца, наложение раунда на финал, перезапись данных HUD при очереди, потеря опроса при невзятом `config.json`, потеря наполовину записанных данных при чтении, лимит свойства 9 КБ, коды подразделений набранные руками, `null → 0`, повторные подразделения в парах, закрытая неделя после смены пар.
- Понятные сообщения на экране при проблемах с ключом/связью; автосжатие длинных имён; скрытие пустых панелей до первых данных.
- Убрана шаблонная телеметрия Phaser (`log.js`) и неиспользуемые файлы шаблона; добавлена проверка продакшн-сборки из подпапки; звук включается по первому нажатию после перезагрузки.

## Что изменилось по сравнению с «Отделами против дракона»

| Было | Стало |
|---|---|
| Герои бьют дракона при каждой оплате | Герои-руководители бьются друг с другом в парах при каждой загрузке |
| Недельный план в рублях, 5 голов дракона = 5 дневных планов | Нет плана в рублях; до 5 звёзд, набираются за выигранный день |
| Данные: оплата за оплатой (`Date/Amount/ROP`) | Данные: накопительные счета по менеджерам; подразделения из справочника |
| Сравнение — суммы | Сравнение — **среднее на сотрудника** (цель 1,20) |
| Публичный GET отдаёт агрегаты по адресу из репозитория | GET по «ключу экрана» (в данных ФИО) |
| Админка: план, оплата, таблица, анимации, PIN | Админка: загрузка, сотрудники, пары, день/неделя, история, анимации, доступ |
| Таблица: `Sales` и `Settings` | Шесть вкладок, ведёт бэкенд |
| Рейтинг подразделений | Рейтинг менеджеров в абсолютных числах |
| Фон — пещера | Фон — храм; бойцы на узком полу |
