# План: «Mortal Sales» — бойцовская версия «Отделов против дракона»

## Context

Есть работающая игра «Отделы против дракона» (Phaser 4 + Vite + TS, бэкенд на Apps Script + Google Sheets, PIN-админка). Её нужно превратить в игру в духе Mortal Kombat: 6 руководителей групп (РГ) — те же герои-маскоты — разбиты на 3 пары и «бьются» на экране офиса. Поводом для боя служит каждый импорт счетов от 20 минут (~раз в 2 часа). Исход дня решает кнопка в админке, а звёзды (жизни) показывают счёт матча за неделю. Дракон убирается.

Собираем на копии проекта (`Mortal combat Tver`), боевую игру не трогаем.

**Найдено при разведке (важно):** копия пока указывает на боевые ресурсы: `git remote origin` = `KonturProject/sales-vs-dragon`, `npm run deploy` публикует в его gh-pages, `public/config.json` смотрит на боевой Web App, `Code.gs` — на боевую таблицу. Поэтому по ответам пользователя делаем всё новое: отвязываем remote, ставим заглушки, не пушим и не деплоим до нового репозитория.

## Решения пользователя

- **Импорт:** через админку вставляется таблица «менеджер → счета от 20 минут на текущий момент». История и сверка накопительных итогов — на моей стороне (я выбираю схему хранения).
- **Матч = неделя = 5 дней = 5 звёзд.** Новую неделю запускает кнопка в админке.
- **Менеджеров 15–30** → общий рейтинг постранично.
- **Изоляция:** новый репозиторий, новая таблица, новый Apps Script со своим PIN.
- Дракон не нужен; герои те же; 3 слева + 3 справа, удалённая перспектива, бойцы выходят к центру.

## Бэкенд: остаёмся на Apps Script + Google Sheets

Вердикт по альтернативам: **не менять.** Данные меняются раз в 2 часа, задержка 3–40 с никому не мешает; команда живёт в Google Таблицах, админка с PIN уже отлажена и бесплатна. Firebase/Supabase дали бы push вместо опроса, но требуют нового аккаунта, своей админ-авторизации, и данные пропали бы из таблицы; Cloudflare Workers — деплой через wrangler ради выгоды, которой у нас нет. Пересмотрим, если экранов станет много (квоты Apps Script) — заранее снижаем нагрузку: кэш ответа GET в `CacheService` ~10 с, сбрасывается при любой записи.

### Схема таблицы (вкладки, создаются скриптом `setupSheets_()` при первом запуске)

|---|---|---|

**Приватность (прошу подтвердить):** раньше GET отдавал только агрегаты; теперь в нём имена менеджеров и их результаты, а URL лежит в публичном `config.json`. Предлагаю «ключ экрана»: свойство `DISPLAY_KEY` в Script Properties (задаётся как PIN), экран открывается один раз по `…/index.html#key=…`, ключ запоминается в localStorage; GET без ключа отдаёт `{ok:false}`. Дёшево и закрывает утечку имён.

Финал дня едет к экранам командой `finale` (уже готовый механизм `commands`: воспроизводится один раз, старше 2 мин отбрасывается), а звёзды и итоги при этом уже записаны в таблицу — то есть состояние верно, даже если экран был выключен.

## Механика боя (предложение — то, о чём вы просили в п. 11)

Вход: `a`, `b` — накопительные за день суммы счетов двух РГ пары (сумма их менеджеров; сырая разница, как вы сказали).

1. **Перевес** `D = |a−b| / (a+b)` ∈ [0..1]. От объёма (ранние 1:0 в 9 утра не должны давать «разгром»): `D_eff = D · min(1, (a+b)/K)`, `K = 10` счетов (настройка).
2. **Ударов у лидера** `nL = 2 + round(6·D_eff)` → 2…8.
3. **Ударов у отстающего** `nW = max(1, round(nL·(1−D_eff)^1.6))` → бьются оба, у равных поровну, у безнадёжного остаётся один отчаянный. При `a=b`: `nL=nW=2`.
4. **Ярусы драмы** по `D_eff` (пороги в `Constants.ts`):
   - **< 0.15 равный бой** — лёгкие удары, чередуются, лишь короткий отшаг.
   - **0.15–0.35 перевес** — отшаги на каждый удар, последний удар лидера **оглушает** (звёздочки над головой ~1.2 с).
   - **0.35–0.6 доминирование** — последний удар **сбивает с ног** (падение, подъём), средняя тряска экрана.
   - **≥ 0.6 разгром** — последний удар: **эпичный отлёт** через полполя с вращением, врезание в край, пыль, стоп-кадр, сильная тряска.
5. **Порядок:** удары отстающего идут в начале (пока не оглушён), затем чередование, серия лидера — комбо в конце. Ничья/равный бой — строгое чередование.
6. Бой запускается **только для тех пар, где счёт изменился в положительную сторону** после импорта; все 3 пары бьются параллельно в своих полосах, старт со смещением ~0.4 с. После боя бойцы возвращаются на места.

**Финал дня** (кнопка «Завершить день»): по очереди для каждой пары — выход в центр, «ДОБИВАНИЕ» лидера дня (серия + отлёт проигравшего), треснувшая звезда падает у проигравшего, плашка победителя. Ничья — обоюдный поклон, звёзды сохраняются. Пятый завершённый день закрывает неделю: победитель пары — у кого больше звёзд (при равенстве — больше счетов за неделю), плашка «ПОБЕДА» и табло до кнопки «Новая неделя».
