## Проверка 04.10: новый Гринч, удары Скруджа, звук

Панель встроенного браузера была скрыта (окно свёрнуто), а в скрытой вкладке игра стоит на паузе. Поэтому проверка шла в отдельном headless Chrome
(временный профиль) на локальном стенде: раунд, затем финал дня, скриншоты каждые 0,4–0,5 с и журнал всех звуковых вызовов с временем.

| Что | Результат |
|---|---|
| Сборка спрайтов | изменились только спрайты Гринча, у Скруджа добавились `hit2`–`hit4`; остальные герои байт в байт прежние |
| Масштаб новых поз | подобран по листу «модель + позы»: голова Гринча ×2,0, корона Скруджа ×1,95 совпадают со стоячими моделями |
| Бледный контур-«наклейка» у поз Гринча | вычищен при сборке (тёмные полупрозрачные пиксели дальше 4 px от рисунка) |
| Клипы | все 8 загружаются и декодируются; тишина в начале (0,3–0,7 с) срезается |
| Раунд | музыка → «РАУНД 2» + «Round two» (0 мс) → «FIGHT!» + голос (1614 мс) → бой; музыка отпускается в конце и затихает через 2,5 с |
| Финал из трёх пар | «Finish her» (1,9 с) → «Fatality» (4,4 с) → «Finish her» (8,5 с) → «Fatality» (10,9 с) → «Finish her» (15,2 с) → «Flawless victory» (17,6 с, у проигравшего 0 счетов); голоса не наслаиваются; звёзды загорелись у победителей |
| Номер раунда за день (бэкенд) | новый тест: 1, 2, 3 в течение дня, повтор запроса не считается, после «Завершить день» снова 1 |

## Что не проверено и почему

| Что | Почему | Как проверить |
|---|---|---|
| **«Новая неделя» и закрытие недели (пятый день) на настоящей таблице** | меняют состояние недели и не отменяются; на живом бэкенде не нажимались | прогнать на копии таблицы или перед началом недели |
| Звук на настоящих колонках | проверялись вызовы и тайминги (headless Chrome), сами голоса и громкость на слух — нет | послушать на офисном экране, громкость — `THEME_VOLUME` / `MASTER_VOLUME` в `Audio.ts` |
| Несколько экранов одновременно | в одной сессии один экран | достаточно открыть ссылку на втором экране |
| Firefox / Safari | проверялся Chrome (встроенный браузер) | при необходимости — открыть экран и админку |
| Дополнительные позы героев | ещё не присланы | интеграция вручную |
| Нагрузка на настоящем слабом ноутбуке | проверен режим `quality=low` в эмуляции | запустить на офисном компьютере, `__debug.power()` только в dev; частота кадров видна по загрузке процессора |
| Время ответа Apps Script под нагрузкой | зависит от Google | опрос с дублирующим запросом и таймаутами уже заложен |
