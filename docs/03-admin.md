# Руководство администратора

Админка — страница `admin.html` рядом с игрой. Вход по PIN-коду (он хранится только в памяти страницы). Через неё делается всё: загрузка данных, сотрудники, пары, завершение дня и недели, настройки. Экран ничего не меняет сам.

## Ритм работы

| Когда | Что делать | Где |
|---|---|---|
| Раз в ~2 часа в течение дня | Загрузить файл «ФИО — счета от 20 минут» (накопительно с начала игрового дня) | **Загрузка данных** |
| Вечером, когда день считается закрытым | Нажать **Завершить день** — на экране финал, проигравшие теряют звезду | **День и неделя** |
| После пятого дня | Экран покажет победителей недели; когда готовы начинать — **Начать новую неделю** | **День и неделя** |
| По мере необходимости | Перевести сотрудника, снять с штата (отпуск), добавить нового | **Сотрудники** |
| Когда меняется расклад | Поменять пары | **Пары и отделы** |

Через ~15 секунд после любого действия экран подхватит результат.

## Вкладки

### День и неделя

- Плашки: номер недели, «День N из M», время последней загрузки, число активных сотрудников, **цель на сотрудника**.
- **Сегодня по парам** — суммы, штат и *среднее* каждой стороны, пометка «впереди» и звёзды. Это ровно то, по чему закончится день.
- **Завершить день** — подтверждение показывает исход каждой пары (кто победит, кто потеряет звезду). Перед показом данные перечитываются, так что цифры свежие. Действие необратимо; не нажимайте до окончания дня.
- **Начать новую неделю** — все звёзды снова 5, счётчики дня и недели в ноль, табло победителей убирается.
- **Звёзды: ручная поправка** — выбрать число звёзд подразделения (ошибочное завершение дня, день «не в счёт»). На экране изменится без анимации.
- **Настройки**: *дней до решающего матча* (1–10) и *цель — среднее счетов на сотрудника* (по умолчанию 1,20). Цель определяет только силу боя на экране: разрыв измеряется в её долях; на исход («кто выиграл») она не влияет.

### Загрузка данных

1. Выберите файл (`.xlsx`, `.csv`, `.txt`) или вставьте текст («ФИО», пробел или табуляция, число). Заголовок не нужен, строки без числа пропускаются. Если выбран файл, вставленный текст не используется.
2. **Прочитать** → предпросмотр. Для каждой строки видно: подразделение, «было → станет», разница и статус:

| Статус | Что значит | Что делать |
|---|---|---|
| ок | значение выросло | — |
| без изменений | то же число | — |
| меньше, чем было | накопительный счёт не может уменьшаться | если это исправление ошибки — поставьте галочку «Разрешить уменьшение», иначе исправьте файл |
| нет в справочнике | такого ФИО нет | выберите подразделение (человек добавится) или «пропустить» |
| неактивен — пропуск | человек выведен из штата | строка не загрузится |
| дубль — учтётся последняя строка | имя встречается дважды | проверьте файл |
| значение не целое | дробь, отрицательное или слишком большое | исправьте файл |

3. Плашки сверху: сколько строк, сколько изменится, сколько неизвестных, уменьшений, неактивных и сколько активных сотрудников не пришло в файле (они остаются как были, **не обнуляются**).
4. **Загрузить** → подтверждение → «Загрузка № N: учтено …». Если неделя уже закрыта, загрузка недоступна: сначала начните новую.

Сопоставление имён не зависит от регистра, «ё/е» и пробелов. Бой на экране начнётся только для пар, у которых показатель хотя бы одной стороны вырос.

### Сотрудники

- Плашки по подразделениям: сколько активных людей в каждом (по ним считается среднее).
- Поиск по ФИО, фильтр по подразделению, «показывать неактивных».
- В таблице всё сохраняется сразу: **подразделение** (выпадающий список), **галочка «Активен»** (снять — человек выпадает из штата и из рейтинга на экране, его прошлые счета остаются), **Изменить** (переименовать), **Удалить** (из справочника; история остаётся — если человек просто в отпуске, лучше снять «Активен»).
- Метка «нет подразделения» — строка, где подразделение пусто или написано неразборчиво (например, набрали руками в таблице). Выберите подразделение в списке.
- **Добавить сотрудника** — ФИО и подразделение.
- **Импорт справочника из файла** — для первичного заполнения и массовых перестановок. Формат: строка с названием подразделения (содержит код `СР1`…`СР9`, например `КЦПК_НП_СР_Тверь_СР1_ГБ`) открывает группу, ниже ФИО её менеджеров; либо два столбца «ФИО | код». Предпросмотр: новых, переведённых, без изменений, отсутствующих в файле; галочка «Сделать неактивными тех, кого нет в файле». Названия подразделений подтягиваются из заголовков. Счета сотрудников не трогаются.

### Пары и отделы

- До трёх пар: выберите левого и правого. Пара № 1 дерётся на задней линии арены, № 3 — на передней. Каждое подразделение — в одной паре; пустая пара допустима. Звёзды остаются у подразделений при смене пар. Подразделения без пары на экране не показываются, но считаются и видны в рейтинге.
- **Подразделения и руководители**: название (для вас) и имя РГ — оно показывается на лайфбаре как «Фамилия И.О.»; если не задано, показывается имя героя.

### История

Только чтение: завершённые дни (подразделение, счета, людей, среднее, исход, звёзды) и последние 200 строк загрузок (кто, сколько, на сколько изменилось). Кнопка «Обновить». Данные подгружаются при открытии вкладки.

### Анимации

Демонстрации на экранах, ничего не меняют: **демо-бой** выбранной пары с введёнными средними (подсказка пишет, какой это ярус по текущей цели), **демо-финал** по сегодняшним цифрам (звёзды не меняются), **конфетти**, **все празднуют**.

### Доступ

- **Ключ экрана.** Экран получает данные только по ключу. «Создать ключ экрана» → ссылка; откройте её один раз на экране — ключ запомнится в браузере. «Создать новый ключ» отключит все старые ссылки.
- **PIN-код**: смена (4–12 цифр). Пять неверных попыток подряд блокируют вход на 10 минут.

## Сообщения об ошибках

| Сообщение | Причина | Решение |
|---|---|---|
| Неверный PIN / Слишком много неверных попыток | PIN неверен; сработала блокировка | подождать указанное время; PIN можно сбросить в меню таблицы «Mortal Sales → Задать PIN администратора» |
| Не удалось связаться с сервером | нет сети или неверный адрес в `config.json` | проверить соединение и `appsScriptUrl` |
| Демо-режим (`useMock=true`) | бэкенд не подключён | вписать адрес Web App и `"useMock": false` |
| В загрузке есть сотрудники, которых нет в справочнике | имя не найдено | добавить в «Сотрудники» или назначить подразделение в предпросмотре |
| Значения стали меньше прежних | накопительный счёт уменьшился | разрешить уменьшение, если это исправление |
| Неделя завершена | попытка загрузки или второго «Завершить день» | начать новую неделю |
| Не заданы пары | нечем завершать день | вкладка «Пары и отделы» |
| Сотрудник с таким ФИО уже есть | дубль | искать в списке (в том числе среди неактивных) |
| Не найдено | запись уже изменена в другом окне | данные обновлены, повторите |
| Ошибка на стороне сервера | вкладка/лимиты/блокировка в Google | повторить; детали — в тексте сообщения и журнале Apps Script |

## Если ошибся

| Ситуация | Как исправить |
|---|---|
| Загрузил не тот файл (значения выше реальных) | загрузить верный файл с галочкой «Разрешить уменьшение» |
| Нажал «Завершить день» раньше времени | вернуть звёзды (вкладка «День и неделя → Звёзды»). Дневные счета уже перенесены в недельные, а день начат с нуля — если нужно, поправьте вручную колонки «За день» и «За неделю до сегодня» на вкладке `Команда` в таблице |
| Человек в отпуске | снять «Активен» — он выйдет из штата и не будет занижать среднее |
| Не тот сотрудник в подразделении | вкладка «Сотрудники», выпадающий список подразделения |
| Нужна другая пара | вкладка «Пары и отделы» (звёзды сохранятся) |
