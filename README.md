# Mortal Sales

Экран для офиса: воронка продаж как турнир в стиле Mortal Kombat. Шесть героев-маскотов — руководители групп — дерутся тремя парами в храме (три слева, три справа, вид издалека). Каждая загрузка счетов «от 20 минут» (~раз в 2 часа) запускает бои. По кнопке «Завершить день» в админке на экране финал: победители в парах получают звезду (за неделю их набирается до 5). Рейтинг менеджеров — в абсолютных числах. Бой и итог дня определяет **среднее число счетов на одного активного сотрудника** (цель — 1,20), а не сумма, поэтому большой отдел не получает преимущества.

*Phaser 4 + Vite + TypeScript, бэкенд на Google Apps Script + Google Таблице, админка на обычном DOM.*

## Быстрый старт

```bash
cd game
npm install
npm run mock-backend    # терминал 1: локальный бэкенд (PIN 1234, 65 выдуманных сотрудников)
npm run dev             # терминал 2
```

- Игра: <http://127.0.0.1:8080/?backend=http://127.0.0.1:8787/exec#key=mock-display-key-1234>
- Админка: <http://127.0.0.1:8080/admin.html?backend=http://127.0.0.1:8787/exec> (PIN `1234`)

```bash
npx tsc --noEmit -p tsconfig.json   # типы
npm run test:fight                  # 33 теста: бой, разбор файлов, логика
npm run test:backend                # 50 тестов бэкенда
npm run build                       # продакшн-сборка в game/dist
```

## Состояние

Игра, админка и бэкенд готовы и проверены (бэкенд — на имитации Google; на настоящих Google Таблицах — первый запуск 01.10.2026).
